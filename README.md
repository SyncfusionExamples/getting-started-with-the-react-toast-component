# Getting Started with the React Toast Component

A quick start project demonstrating how to create and configure the Syncfusion React toast component with various positions, timeout settings, and HTML template rendering.

## Overview

This project provides an introduction to the Syncfusion React Toast component. It includes examples showing how to implement toast notifications with different positions, configure timeout durations, and render custom HTML templates within toast messages.

## Features

- Multiple toast position options
- Configurable timeout durations
- HTML template support for custom content
- Easy React integration
- Practical usage examples

## Prerequisites

- Visual Studio Code
- NodeJS and npm (latest stable version)
- Basic React knowledge

## Installation

1. Clone the `getting-started-with-the-react-toast-component` repository
2. Navigate to the project directory
3. Install dependencies:
   ```
   npm install
   ```
4. Install Syncfusion React Toast:
   ```
   npm install @syncfusion/ej2-react-notifications
   ```

## How to Run

1. Open the cloned repository in Visual Studio Code
2. Run the development server:
   ```
   npm start
   ```
3. View the output in your browser

## Configuration

Configure toast notifications by adjusting:

- Toast position (top, bottom, left, right options)
- Timeout values for display duration
- Custom HTML templates for toast content
- Notification styling
